# MindVault AI

Prompt for Lovable:

Design a modern, calming, privacy-focused AI mental health companion web app called MindVault. The app is a Progressive Web App (PWA) built with React + Vite and Tailwind CSS.

Theme

 Minimal, clean, calming aesthetic

 Soft gradients using lavender, blue, teal, and white

 Rounded cards (xl radius)

 Glassmorphism where appropriate

 Smooth animations and micro-interactions

 Dark mode as the default with optional light mode

 Accessible typography with plenty of whitespace

 Friendly and trustworthy design

Core Message

The entire experience should emphasize:
"Everything stays on your device. No cloud. No server. Complete privacy."
